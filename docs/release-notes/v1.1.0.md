# YouTube Downloader v1.1.0

## Release Type

User experience feature release.

## Highlights

- Added a Preview section that shows the checked video's thumbnail, title, and length before downloading.
- Made the main app content vertically scrollable so diagnostics and lower controls remain reachable in smaller windows.
- Switched preview duration text from compact timestamps to readable units such as `10 sec` or `3 hr 50 min 22 sec`.
- Kept empty preview states compact with `Nothing to preview` instead of reserving a blank thumbnail rectangle.
- Added optional channel, upload date, and live/upcoming status details when `yt-dlp` returns them.
- Reworked the link-check flow so one metadata fetch updates both the preview and quality options.
- Reused checked title and upload-date metadata during download setup when the current URL still matches.
- Added Pillow as a runtime dependency for thumbnail decoding and resizing.

## Validation Checklist

- Run the app from source and confirm startup diagnostics still complete.
- Paste a valid YouTube URL and confirm the preview image, title, length, and quality options appear.
- Resize the window to minimum height and confirm the full app can be reached with the right-side scrollbar.
- Confirm invalid/private/unavailable links clear the preview and keep Download disabled.
- Confirm video and audio-only downloads still save successfully after preview metadata loads.
- Build the release EXE and verify thumbnail previews display in the packaged app.
