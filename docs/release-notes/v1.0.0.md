# YouTube Downloader v1.0.0

## Release Type

First public Windows release candidate.

## Highlights

- Windows desktop GUI for single YouTube video/audio downloads.
- Video downloads save as MP4.
- Audio-only downloads support MP3, WAV, AAC, and FLAC.
- Startup diagnostics show app/dependency/network health.
- Packaged build can bundle `ffmpeg`, `ffprobe`, and a JavaScript runtime for `yt-dlp`.
- Download flow cleans temp files, handles repeated filenames, and reports real errors.
- Public UI includes grouped controls, saved settings, paste/test-link actions, and an app icon.

## Known Limitations

- Windows-first release only.
- No playlists, batch downloads, or queue management.
- YouTube extractor behavior may require future `yt-dlp` updates.
- One-file PyInstaller builds create temporary `_MEI*` folders while running; clean shutdown should remove them.

## Release Checklist

- Build with `build_exe_latest.bat`.
- Run the EXE on a clean Windows machine without local Python, `ffmpeg`, or `ffprobe`.
- Confirm startup diagnostics show no failures.
- Verify video download, audio-only MP3, repeated same-URL download, invalid URL failure, and close-during-download cleanup.
- Include third-party license/notice files for the exact bundled `ffmpeg`, `ffprobe`, JavaScript runtime, `yt-dlp`, and `yt-dlp-ejs` versions.
- Attach the ZIP or EXE to the GitHub release.
